# 洞穴与主城自动楼层识别

2026-10-30。优先覆盖室外步行进入洞穴、铁炉堡及返回。桥上/桥下按用户要求暂不作为完成条件。

## 使用

更新 `addons/AutonomousDriving` 至 0.3.0，在游戏内重新加载并重启桌面客户端。只支持新版 v3 色块，Pico 无需更新。实时起点无需手动输入高度。点击终点，客户端在同一水平位置的表面中选择已有完整步行连接且路径较近的一层；显示和路线保留实际选择的高度。这是默认目的地策略，不能推断用户想去两个都可达楼层中的哪一个。

如果刚启动就站在同区域的重叠表面上，客户端保留多个候选；短距离步行到能区分表面的位置后自动识别。已点击开始的任务在辨认期间等待，不发送移动命令。只在原地站立、或者沿完全重叠的平行通道移动，信息可能始终不足；区域名称不等于楼层。

## 判断依据

- `C_Map.GetBestMapForUnit('player')` 已在原协议提供当前 UI 地图；0.3.0 增加 `GetSubZoneText()`（空时使用 `GetRealZoneText()`）的名称标识，以及 `IsIndoors()`、`IsFalling()` 的已知/未知状态。监听三个区域变化事件并持续采样。可选 API 不存在、返回秘密值或抛错时保留未知。
- 所有地面候选来自当前静态碰撞导航包。连续观察之间逐一验证完整步行连接，限制绕路长度和三维长度；不能借远处楼梯把角色从一层认到另一层，也不使用规划路线作为角色所在楼层的证据。
- 遥测水平坐标按 1/16 码取整。查询涵盖取整格内中心及边角，最多每轴偏移 1/32 码；这些点仅作为连通性证据，原始遥测坐标不变。路线规划端点仍保留严格水平坐标判定。
- 插件重载、跨大陆、时间中断超过 0.75 秒、异常位移、加载、死亡、飞行、游泳、载具和下落会丢弃旧轨迹。区域编号变化本身不会清除已确认的连通轨迹。
- 每次局部连接最多展开 1,024 次；最多检查 64 组候选连接，20 ms 后不再启动下一次查询。搜索预算不足会保留不确定性，不能当作某层不可达的证据。冷加载不包含在这一查询预算内，仍在后台采集线程中进行；原始采集时间保留，250 ms 新鲜度保护保持生效。

## 区域数据与来源

`data/region-context.json` 从本机当前 1.60.1.70685 提取结果生成，包含 993 个区域名称标识、60 个 UI 地图名称、61 条地图分配记录。AreaTable 有 46 条加密记录被跳过，清单明确记录，缺失名称显示编号。名称和地图框只作上下文，不参与未经验证的高度筛选。

本机 Forever 源码 `DB2Stores.cpp::CheckUiMapAssignmentStatus` 结合 XYZ、AreaID、WMO 放置和组信息判断地图分配。70685 的铁炉堡地图分配 Z 范围为 -1,000,000 到 +1,000,000；所以仅获得 uiMap=1455 不能排除山体上方地面。当前不伪造 WMO 组观测。

导出器 `tools/export_region_context.py` 在 WSL 运行，复用本机 ForeverTracker 的 MIT DB2 读取器（提交 `1f2a8a1f439788af02f60e9d53f0a8bf71d7eaf0`），只读服务端源码和已提取数据，不修改服务端、数据库或运行状态。输出记录各表 SHA256、布局检查、跳过记录和构建版本，版本与导航包不符时拒绝导出。

[Forever 客户端导出的 C_Map 接口](https://github.com/Atraeau/WoW-Addons/blob/main/docs/api/Map-Instances-World/C_Map.md)也列出了 GetBestMapForUnit；该外部接口清单为 70170，当前区域数据使用本机 70685，不混用版本。

## 验证与限制

永久测试 `tests/test_floor_tracking.py` 覆盖入口/出口、区域切换、初始多候选、停留不乱选、时间与会话重置、下落、重复帧、预算失败、协议往返和实际 Lua 区域事件。后台慢查询另有线程隔离测试，待辨认时不规划、不发令另有运行时测试。

使用当前导航包 `7a4606dd9c967264`，以完整路线生成模拟行走序列，再经过实际 v3 编码/解码的取整精度进行往返跟踪：

| 场景 | 单程路线 | 结果 |
| --- | --- | --- |
| 铁炉堡外 `(-5040,-800)` → 城内 `(-4821,-1152)` | 470.237 码 | 自动选终点地面约 502.252 码，进出连续跟踪 |
| 骷髅石洞穴 `(1452,-4788)` → `(1440,-4830)` | 43.681 码 | 从约 33.529 到 22.804 码并原路返回 |

详细样本数与耗时写入 `runtime/floor-tracking/validation.json`。冷启动数据加载约半秒，样本保持真实采集时刻，不冒充新鲜观测。现有导航全包回归门禁已通过；本次没有改变或发布网格、没有修改 DLL。

这些是离线验证，不代表实际角色已经走过路线。真实游戏中的区域名称、室内状态、入口切换、楼梯和碰撞偏差仍需行走验收。推定的是地面高度，不能测量角色在空中的真实高度；动态门、电梯、船只和跨副本移动仍不在本次范围。
